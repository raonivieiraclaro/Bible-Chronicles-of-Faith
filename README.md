# Bíblia Sagrada — Chronicles of Faith

**by Raoni Claro**

Protótipo RPG 2D Godot 4.3 para Android, inspirado na estética 16-bit dos RPGs de SNES, com recursos originais. Projeto narrativo baseado no cânon católico (73 livros).

## Estado
Versão inicial experimental: seleção de idioma PT-BR/EN/ES, narrativa de Gênesis a Noé e batalha simples por turnos. Não é ainda a campanha completa nem inclui trilha sonora final.

## Abrir
Abra `project.godot` no Godot 4.3 e execute a cena principal.

## APK
O workflow `.github/workflows/android.yml` executa exportação Android debug no GitHub Actions. Após sucesso, baixe o artefato da execução em Actions. A compilação precisa ser validada.
